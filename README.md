# Random Activity Picker

A desktop productivity tool built in Python using Tkinter to reduce decision fatigue.

## Problem
When overwhelmed or burnt out, choosing what to do next becomes a blocker.
This tool removes that friction by making the decision for the user.

## Features
- Randomized hobby and break suggestions
- Persistent user-defined activities (stored locally)
- Simple state-based UI (single window, dynamic controls)

## Technical Details
- Python + Tkinter GUI
- Local file persistence using text files
- Modular picker logic for easy extension

## Future Improvements
- JSON-based storage instead of text files
- Themed UI and accessibility improvements
- Port logic to a web app (React)
